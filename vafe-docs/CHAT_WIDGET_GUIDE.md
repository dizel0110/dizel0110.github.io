# 🪁 V-AFE Chat Widget — Руководство пользователя

## 🎯 Что это?

Умный чат-помощник на сайте dizel0110.github.io с **тремя режимами работы**:

| Режим | Иконка | Для чего | База знаний |
|-------|--------|----------|-------------|
| **Кайтинг** | 🪁 | Вопросы о кайтбординге | 34 концепта V-AFE |
| **О себе** | 👤 | Информация о Дмитрии | 16 записей |
| **Общий** | 💬 | Универсальные вопросы | Смешанная база |

---

## 🚀 Как использовать

### Для посетителей сайта

1. **Открыть чат:** Нажмите на круглую кнопку в правом нижнем углу
2. **Выбрать режим:** Используйте переключатель внизу хедера
3. **Задать вопрос:** Введите текст или выберите готовое предложение
4. **Получить ответ:** Чат найдёт релевантные записи в базе

### Примеры запросов

#### Режим "Кайтинг" 🪁
- "Что такое вымпельный ветер?"
- "Как правильно стартовать?"
- "Поза семёрки — как делать?"
- "Как ехать против ветра?"
- "Как использовать чоп?"

#### Режим "О себе" 👤
- "Расскажи о себе"
- "Какие у тебя проекты?"
- "Как с тобой связаться?"
- "Где ты находишься?"
- "Какие у тебя навыки?"
- "Открыт к работе?"

#### Режим "Общий" 💬
- "Привет!"
- "Что ты умеешь?"
- "Помощь"
- "О проекте V-AFE"

## 🎨 Особенности

### Контекстная память
Чат помнит последние сообщения и учитывает контекст:

```
Вы: "Как правильно стартовать?"
Чат: [отвечает про старт]

Вы: "А что потом?"
Чат: [понимает, что речь о продолжении старта]
```

### Источники
Каждый ответ сопровождается ссылками на исходные записи:

```
📚 Источники:
[Вымпельный ветер] [Поза Семерки] [Старт в слив]
```

### Временные метки
У каждого сообщения есть время отправки.

### Очистка истории
Кнопка 🗑️ в хедере очищает историю переписки.

## 🔧 Для разработчиков

### Структура виджета

```typescript
// Режимы чата
type ChatMode = 'vafe' | 'about' | 'general';

// База знаний
interface Concept {
  id: number;
  tag: string;
  concept: string;
  description?: string;
  physics?: string;
  mechanics?: string;
  details?: string;
}

// Сообщение
interface Message {
  role: 'user' | 'assistant';
  content: string;
  sources?: Concept[];
  timestamp: number;
  mode?: ChatMode;
}
```

### Добавление новых записей

1. Откройте `data/v-afe_core.json` или `data/about_dmitry.json`
2. Добавьте новую запись:
```json
{
  "id": 35,
  "tag": "Category",
  "concept": "Название концепта",
  "description": "Описание",
  "details": "Детали"
}
```
3. Запустите синхронизацию:
```bash
python scripts/sync_widget.py
```
4. Закоммитьте изменения:
```bash
git add .
git commit -m "Add new concept"
git push
```

### Кастомизация

#### Изменить цвета режимов

Откройте `VafeChatWidget.tsx`, найдите `MODES`:

```typescript
const MODES: Record<ChatMode, ModeConfig> = {
  vafe: {
    id: 'vafe',
    name: 'Кайтинг',
    icon: '🪁',
    color: '#0077be',        // ← Ваш цвет
    gradient: 'linear-gradient(135deg, #0077be, #00a8e8)',
    // ...
  },
  // ...
};
```

#### Добавить новый режим

1. Добавьте тип режима:
```typescript
type ChatMode = 'vafe' | 'about' | 'general' | 'custom';
```

2. Добавьте конфигурацию:
```typescript
const MODES: Record<ChatMode, ModeConfig> = {
  // ...
  custom: {
    id: 'custom',
    name: 'Ваш режим',
    icon: '🎯',
    color: '#ff0000',
    gradient: '...',
    suggestions: ['...', '...'],
    knowledgeBase: [...]
  }
};
```

3. Обновите переключатель в JSX.

## 🐛 Известные ограничения

1. **Поиск по keywords** — не семантический, а по ключевым словам
2. **Нет LLM** — ответы генерируются из шаблонов
3. **Нет бэкенда** — вся база встроена в виджет
