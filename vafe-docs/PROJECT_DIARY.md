# V-AFE Integration Project Diary

## 📅 15.03.2026 — Контекстный чат для dizel0110.github.io

### Цель
Создать умный чат-виджет, который меняет контекст в зависимости от раздела сайта:
- **Главная** → универсальный ассистент (О Дмитрии + Проекты)
- **V-AFE раздел** → кайтбординг инструктор
- **Контакты** → помощник по связи

---

### 🎯 Архитектурные решения

#### 1. Гибридная модель ✅ РЕАЛИЗОВАНО
- Переключатель режимов внутри чата (всегда виден)
- 3 режима: **Кайтинг** 🪁 / **О себе** 👤 / **Общий** 💬
- Авто-смена контекста при скролле (опционально, можно добавить позже)
- Иконка и цвета меняются по контексту

#### 2. Источники данных
```
vortex-afe/
├── data/
│   ├── v-afe_core.json      # Кайтинг база (34 концепта)
│   └── about_dmitry.json    # О себе (16 записей) ← НОВОЕ!
└── web/
    └── VafeChatWidget.tsx   # Виджет с переключателем
```

#### 3. Режимы чата

| Режим | Иконка | Цвет | База | Предложений |
|-------|--------|------|------|-------------|
| Кайтинг (vafe) | 🪁 | Синий | 34 концепта | 6 |
| О себе (about) | 👤 | Фиолетовый | 16 записей | 6 |
| Общий (general) | 💬 | Зелёный | 16 смешанных | 6 |

### 🔧 Технические детали

#### Текущая структура виджета
```typescript
interface ChatMode {
  id: 'vafe' | 'about' | 'general';
  name: string;
  icon: string;
  knowledgeBase: Concept[];
  suggestions: string[];
}
```

#### Контекстные триггеры
```javascript
// При скролле определяем видимую секцию
const visibleSection = getVisibleSection(); // 'hero' | 'vafe' | 'contact'

// Меняем режим чата
if (visibleSection === 'vafe') setMode('vafe');
if (visibleSection === 'about') setMode('about');
```
