# V-AFE Chat Widget — Changelog

## v2.1.0 — Авто-смена режимов и раздельная память (15.03.2026) ✅

### Добавлено
- ✅ **Авто-смена режима при скролле** — Intersection Observer отслеживает видимую секцию
- ✅ **Раздельная история для каждого режима** — переключение не стирает контекст
- ✅ **Аватарка с GitHub** — загружается с avatars.githubusercontent.com
- ✅ **Умная привязка к секциям**:
  - Hero → Общий режим
  - Technical Core → Кайтинг
  - Investor/About/Contact → О себе

### Технические детали
- `messagesByMode` — отдельный state для каждого режима
- `handleScroll` — определяет видимую секцию
- `modeMapping` — маппинг секций на режимы чата
- Аватарка: fallback на ui-avatars.com при ошибке

### Как работает авто-смена
```typescript
const modeMapping = {
  'hero': 'general',
  'technical-core': 'vafe',
  'lifestyle': 'general',
  'investor': 'about',
  'about': 'about',
  'contact': 'about'
};
```
