# dizel0110 Portfolio — Architecting LLMs. Mastering the Wind.

Personal brand ecosystem for **dizel0110** — LLM & ML Engineer building the next generation of Agentic AI.

## 🎨 Design Philosophy

**Red Sea Cyber-Minimalism**
- Deep Slate background (#020617) with organic film grain
- El Gouna water gradients (Turquoise → Cyan)
- Clash Display + Geist Mono typography
- Asymmetric Bento-Grid layout

## 🚀 Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Animations:** Framer Motion (organic, human-like)
- **Smooth Scroll:** Lenis
- **Icons:** Lucide React
- **Deployment:** GitHub Pages / Vercel

## 📁 Project Structure

```
dizel0110-portfolio/
├── src/
│   ├── components/

│   │   └── Navigation.tsx        # Fixed nav + mobile menu

```

## 🛠️ Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
