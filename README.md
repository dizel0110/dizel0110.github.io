## 🎨 Design Philosophy

**Red Sea Cyber-Minimalism**
- Deep Slate background (`#020617`) with organic film grain
- El Gouna water gradients (Turquoise → Cyan)
- Clash Display + Geist Mono typography
- Asymmetric Bento-Grid layout

## 🚀 Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Animations:** Framer Motion (organic, human-like)
- **Smooth Scroll:** Lenis
- **AI Chat Widget:** V-AFE RAG (runs on vafe-api.vercel.app)
- **Icons:** Lucide React
- **Deployment:** GitHub Pages (site) + Vercel (API)
